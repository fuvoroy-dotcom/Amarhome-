# **App Name**: Amar Bari Estimator

## Core Features:

- Structural Dimension Input: Allows users to input detailed dimensions for foundation bases, columns, and beams (length, width, height/thickness) in both feet and inches, facilitating precise material calculations.
- Steel Rebar Specification: Enables users to specify steel rebar parameters such as the number of rods for columns and beams, main rebar diameter, ring rebar diameter, ring gap, and the quantities for base reinforcement.
- Construction Material Calculation Engine: Core logic that calculates the total concrete volume, and then estimates required quantities of cement (bags), sand (CFT), chips (CFT), and the overall weight of steel rebar (kg), including separate weights for main and ring rebar, based on a fixed 1:1.5:3 mix ratio.
- Instant Result Display: Displays calculated material quantities immediately upon user request, presenting them clearly and prominently in an organized output section.
- Bengali Language Support: The entire user interface, including input labels, descriptions, and result display, is presented in Bengali to cater to the target audience.
- AI Construction Advisory Tool: An AI tool that provides general guidance or contextual information related to material usage, construction best practices, or insights into structural elements based on the user's input.

## Style Guidelines:

- Color Palette: A light scheme evoking stability and professionalism. The primary color is a refined blue-grey (#3B4A5B), reminiscent of solid construction materials, providing a strong anchor for textual elements. The background is an almost-white shade of the same hue (#EFF1F3), offering a clean and subtle backdrop. An accent color, a vibrant cyan (#2AA9CB), will be used for interactive elements and key highlights to draw attention and guide the user.
- All text will use 'Inter', a modern sans-serif typeface, chosen for its clear legibility, neutrality, and objective appearance, suitable for a precision-focused calculator application. It provides excellent readability for both inputs and results.
- Utilize simple, outline-style icons (e.g., '🏗️', '⚙️', '📊') for structural dimensions, settings, and results sections. These should be minimalist, modern, and universally recognizable to quickly convey meaning without cluttering the interface.
- The layout will be clean and organized, employing a responsive three-column grid for larger screens (Input, Settings, Results) and stacking vertically on smaller devices. Ample white space and distinct card-like sections will separate content blocks, enhancing user focus and data comprehension.
- Subtle, quick feedback animations will be incorporated for interactive elements, such as slight background changes or pushes on button clicks, to provide a tactile feel without distracting from the primary calculation process. Result updates should transition smoothly.
